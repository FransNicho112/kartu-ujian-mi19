Generator Kartu Ujian

Nama, Kelas, dan Nomor Ujian Terisi Otomatis Mengikuti Excel

1

Unggah Excel Data Siswa Dibawah

Pilih file .xlsx berisi daftar siswa.

2

Periksa data

Cocokkan jumlah siswa dan rentang nomor ujian tiap kelas. Baca peringatan (jika ada) sebelum lanjut.

KelasSiswaNo. ujian

Nomor ujian disusun dari kode sekolah 19, tingkat kelas 2 digit, dan nomor urut 3 digit. Kelas A dan B sama-sama mulai dari 001.

3

Atur judul kartu

Pilih jenis ujian dan semester, lalu isi tahun pelajaran (dua digit terakhir). Semua wajib diisi supaya tidak ada kartu yang tercetak dengan tahun lama.

TAHUN PELAJARAN 20 – 20

4

Unduh kartu

Klik Tombol Di bawah, File Word Berisi Kartu Semua Siswa.

File Excel dibaca langsung di browser ini dan tidak dikirim ke server mana pun.
